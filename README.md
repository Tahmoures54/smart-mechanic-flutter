## ⚠️ سلب مسئولیت و شرایط استفاده

**هشدار مهم:** اپلیکیشن «مکانیک هوشمند» یک ابزار **کمکی و اطلاعاتی** است که با استفاده از هوش مصنوعی و تحلیل داده‌های صوتی، **پیشنهادهایی** برای عیب‌یابی خودرو ارائه می‌دهد. این تشخیص‌ها به هیچ عنوان **قطعی، تخصصی یا جایگزین نظر مکانیک حرفه‌ای** نیستند.

- **مسئولیت استفاده:** هرگونه اقدام، تعمیر، هزینه یا خسارت ناشی از اعتماد به نتایج اپلیکیشن، کاملاً بر عهده کاربر است و توسعه‌دهنده(گان) هیچ‌گونه مسئولیت قانونی، مالی یا جانی در قبال آن ندارند.
- **مشاوره تخصصی:** اکیداً توصیه می‌شود پیش از هرگونه اقدام عملی روی خودرو، با یک **تعمیرکار مجاز و متخصص** مشورت کنید.
- **دقت اطلاعات:** اطلاعات ارائه‌شده ممکن است کامل یا دقیق نباشند. مدل هوش مصنوعی ممکن است خطا کند.
- **منابع خارجی:** نقشه‌ها و اطلاعات تعمیرگاه‌ها توسط سرویس‌های شخص ثالث (Google) تأمین می‌شوند و صحت آنها تضمین نمی‌شود.
- **پذیرش شرایط:** با نصب و استفاده از این نرم‌افزار، شما می‌پذیرید که توسعه‌دهنده تحت هیچ شرایطی پاسخگوی خسارات مستقیم، غیرمستقیم، تصادفی یا تبعی ناشی از استفاده از این برنامه نخواهد بود.

**برای متن کامل و الزام‌آور، فایل [DISCLAIMER.md](DISCLAIMER.md) را مطالعه کنید.**

## ✨ ویژگی‌های کلیدی

- **🧠 عیب‌یابی با هوش مصنوعی**  
  شرح مشکل خودرو را به‌صورت متنی وارد کنید تا مدل AI تشخیص دقیق، علل احتمالی و راه‌حل‌های پیشنهادی را ارائه دهد.

- **🎤 ضبط و تحلیل صدای موتور**  
  صدای موتور را ضبط کنید. ویژگی‌های صوتی مانند RMS، فرکانس غالب، مرکز طیف و نمودار فرکانس استخراج و برای تشخیص دقیق‌تر استفاده می‌شود.

- **📍 یافتن تعمیرگاه‌های نزدیک**  
  با استفاده از Google Places API، تعمیرگاه‌های اطراف شما نمایش داده می‌شوند و می‌توانید مستقیماً روی نقشه مشاهده کنید.

- **🔐 احراز هویت با OTP**  
  ورود و ثبت‌نام با شماره موبایل و کد یکبارمصرف (OTP) پیاده‌سازی شده است.

- **💳 سیستم اعتبار و پرداخت**  
  کاربران می‌توانند بسته‌های اعتباری خریداری کنند یا اشتراک طلایی را برای استفاده نامحدود فعال کنند.

- **📋 تاریخچه عیب‌یابی‌ها**  
  تمام تشخیص‌های قبلی شما ذخیره شده و قابل مرور هستند.

- **🌙 تم تاریک و فونت وزیرمتن**  
  طراحی مدرن با تم تاریک و فونت فارسی وزیرمتن برای تجربه کاربری بهتر.

- **🔄 پشتیبانی از Pull-to-Refresh**  
  در لیست‌ها و داده‌ها، با کشیدن انگشت به پایین، اطلاعات به‌روز می‌شوند.
