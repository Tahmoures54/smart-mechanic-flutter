تولید دارایی‌های برند از لوگوی ریشه (`logo.png`):

```bash
python3 tool/generate_branding.py
```

سپس (اگر Flutter SDK نصب است):

```bash
flutter pub get
dart run flutter_launcher_icons
dart run flutter_native_splash:create
```

منبع هویت: چرخ‌دنده + قفل طلایی + پیچ‌گوشتی و آچار.
خروجی در `assets/branding/` و `android/app/src/main/res/mipmap-*`.
